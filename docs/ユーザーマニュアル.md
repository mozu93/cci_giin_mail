## 1. 起動とログイン

### 起動方法

デスクトップまたはスタートメニューの **「商工会議所メール配信システム」** をダブルクリックします。

### ログイン

起動するとログイン画面が表示されます。

- **担当者名** のドロップダウンから自分の名前を選択し、「ログイン」をクリックします。
- 担当者名が表示されない場合は、管理者に登録を依頼してください。

> **画面右上にバージョン番号**（例：`v1.0.0`）が表示されます。

---

## 2. 画面の構成

ログイン後、以下のタブが表示されます。

| タブ | 用途 |
|------|------|
| 名簿管理 | 会員情報の閲覧・登録・編集 |
| 会議管理 | 会議の作成、事前入力、当日受付 |
| メール送信 | 一斉メールの作成・送信 |
| テンプレート | メール本文テンプレートの管理 |
| 設定 | 担当者・接続設定（管理者向け） |
| 送信履歴 | 送信済みメールの確認 |

## 3. 名簿管理

### 3-1. 会員一覧の表示

「名簿管理」タブを開くと会員一覧が表示されます。

- **キーワード検索**：事業所名・氏名・会員番号で絞り込めます
- **役職フィルター**：特定の役職のみ表示できます
- **議員退任者を含む**：チェックすると退任者も表示されます
- **A- / A+** ボタン：文字サイズを調整できます（設定は次回起動時も維持されます）

### 3-2. 会員の追加

「追加」ボタンをクリックして会員編集ダイアログを開きます。

| 項目 | 必須 | 説明 |
|------|------|------|
| 会員番号 | ◎ | 重複不可 |
| 会議所役職 | | 副会頭・常議員など |
| 事業所名 | ◎ | |
| 事業所名フリガナ | | 検索・受付に使用 |
| 役職名 | | 代表取締役など |
| 氏名 | ◎ | |
| 氏名フリガナ | | 検索・受付に使用 |
| 備考 | | |
| メールアドレス | | 最大5件・ラベル付き |
| 顔写真 | | JPG/PNG/BMP（証明写真サイズ推奨） |

「保存」をクリックして登録します。

### 3-3. 会員の編集

一覧から会員をダブルクリック、または選択して「編集」ボタンをクリックします。  
編集時は**変更理由の入力が必須**です。

### 3-4. 議員退任処理

退任した会員を選択して「議員退任」ボタンをクリックします。  
データは削除されず、「議員退任者を含む」チェックで確認できます。

### 3-5. 顔写真の登録

会員編集ダイアログの「顔写真」グループで「写真を選択」をクリックします。  
証明写真サイズの画像（JPG/PNG）を選択してください。写真はデータベースに保存されます。

### 3-6. インポート（Excelから一括登録）

「インポート」ボタンをクリックし、Excel ファイルを選択します。  
列の対応付けを確認して「インポート実行」をクリックします。

### 3-7. エクスポート

「エクスポート」ボタンをクリックして Excel または CSV 形式で出力します。

### 3-8. 変更履歴の確認

会員を選択して「変更履歴」ボタンをクリックすると、過去の変更内容と変更理由を確認できます。

## 4. 会議管理・受付

### 4-1. 会議の作成

「会議管理」タブ上部の「新規作成」ボタンをクリックします。

| 項目 | 説明 |
|------|------|
| 会議名 | 例：第50回定時総会 |
| 開催日 | カレンダーから選択 |
| 対象者 | 全員 または 役職指定（常議員会など） |

### 4-2. 事前入力タブ

会議作成後、「事前入力」タブで出欠状況を事前に登録します。

- **ステータス**：未回答 / 出席 / 代理 / 委任 / 欠席
- 代理の場合は代理者の役職名・氏名も入力できます
- キーワード検索・ステータスフィルターで絞り込めます

#### 委任について

- 委任は本人が書面で出席を委任する形式です（代理人の来場なし）
- 事前に「委任」と入力しておくと、受付タブを開いた際に自動的に当日受付も「委任」にセットされます

### 4-3. 受付タブ

当日の受付業務を行います。

**左側の写真パネル：** 行を選択すると顔写真と氏名が表示されます。

**当日受付の列：** ドロップダウンから選択します。
- 空欄（未受付）
- 出席
- 代理
- 委任
- 欠席

**集計バー（上部）：** 出席・代理・委任・欠席・未受付・合計が3秒ごとに自動更新されます。

**検索：** 事業所名・氏名・会員番号で絞り込めます。  
**A- / A+** ボタンで文字サイズを調整できます。

### 4-4. 受付ログタブ

受付操作（誰がいつ何を操作したか）のログを確認できます。

## 5. メール送信

### 5-1. 送信の流れ

**Step 1 → Step 2 → Step 3 → Step 4 → Step 5** の順に設定します。

### Step 1：宛先条件

送信先一覧から対象の会員にチェックを入れます。

- **全選択 / 全解除** ボタンで一括操作できます
- **検索欄** で事業所名・氏名・会員番号・フリガナで絞り込めます
- **A- / A+** ボタンで文字サイズを調整できます

> メールアドレスが未登録の会員は送信対象になりません。画面下部に件数が表示されます。

### Step 2：テンプレート・署名選択

送信するメールのテンプレートと署名をドロップダウンから選択します。  
選択すると右側のプレビューに内容が表示されます。

### Step 3：差し込みデータ（任意）

各会員に個別のデータ（金額・日程など）を差し込む場合に設定します。

1. 「差し込み列を設定」ボタンをクリック
2. col1〜col5 の列と、テンプレートで使うラベル名を設定
3. 「差し込みデータを読み込む」でExcelファイルを選択
4. テンプレート内で `{col1}` や `{参加費}` のように使用できます

**差し込みプレビュー** ボタンで、実際に差し込まれた状態のメールを確認できます。

### Step 4：添付ファイル（任意）

**全社共通ファイル：** 全員に同じファイルを添付します。  
**会社別フォルダ：** フォルダを指定すると、会社名に一致するファイルを各社に個別添付します。

> 「添付ファイルを確認・設定」ボタンで設定済みの添付ファイルを確認できます。

### Step 5：最終確認・送信

1. **ジョブ名** を入力します（例：2026年6月 総会案内）
2. **テスト送信** ボタンで、設定タブに登録したテスト宛先に1通送信して確認できます
3. **差し込みプレビュー** ボタンで最終確認できます
4. **送信実行** ボタンをクリックすると確認ダイアログが表示されます
5. 内容を確認して「送信する」をクリックすると送信が開始されます

**すべてクリア** ボタンで Step 1〜4 の設定をすべて初期化できます。

## 6. テンプレート管理

「テンプレート」タブでメール本文テンプレートを管理します。

### 差し込みタグ一覧

テンプレート本文内で以下のタグを使用すると、送信時に各会員の情報に置き換えられます。

| タグ | 置き換え内容 |
|------|------------|
| `{会社名}` | 事業所名 |
| `{事業所名}` | 事業所名（同上） |
| `{役職名}` | 役職名 |
| `{氏名}` | 氏名 |
| `{col1}`〜`{col5}` | 差し込みデータの各列 |
| `{ラベル名}` | 差し込みデータのラベルを設定した場合 |

---

## 7. 送信履歴

「送信履歴」タブで過去の送信記録を確認できます。

- 送信日時・ジョブ名・担当者・送信件数が表示されます
- 個別の送信先・件名・本文も確認できます

## 8. アップデートの通知

新しいバージョンが公開されると、起動時に画面上部に黄色いバナーが表示されます。

```
新しいバージョン v1.0.1 が利用可能です        [ダウンロード]
```

1. 「ダウンロード」ボタンをクリックするとインストーラーが自動でダウンロードされます
2. ダウンロード完了後「今すぐ更新して再起動」ボタンが表示されます
3. クリックするとインストーラーが起動し、アプリが最新版に更新されます

## 9. よくある質問

**Q. テンプレートを選択したのにプレビューが表示されない**  
A. テンプレートを選択後、「テンプレートを選択してください」に戻すと消えます。再度テンプレートを選択してください。

**Q. 送信先にチェックを入れたのに「0件選択」と表示される**  
A. チェックを入れた会員にメールアドレスが登録されていない可能性があります。名簿管理でメールアドレスを確認してください。

**Q. テスト送信はどこに届きますか？**  
A. 設定タブの「テスト送信先」に登録されているメールアドレスに届きます。

**Q. 受付タブで写真が表示されない**  
A. 名簿管理の編集ダイアログで顔写真を登録してください。写真未登録の会員は「写真なし」と表示されます。

**Q. 文字が小さくて見づらい**  
A. 各タブに「A-」「A+」ボタンがあります。クリックで文字サイズを調整できます（次回起動時も設定が維持されます）。
