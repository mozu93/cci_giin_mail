## 1. 起動とログイン

### 起動方法

デスクトップまたはスタートメニューの **「商工会議所メール配信システム」** をダブルクリックします。

### ログイン

起動するとログイン画面が表示されます。

- **担当者名** のドロップダウンから自分の名前を選択し、「ログイン」をクリックします。
- 担当者名が表示されない場合は、管理者に登録を依頼してください。

### 閲覧専用ログイン

出欠の確認だけを行いたい場合は、担当者を選択せずに「**閲覧専用でログイン**」ボタンをクリックします。  
編集はできませんが、会議管理タブの出欠状況のみを閲覧できます（他のタブは表示されません）。

> **画面右上にバージョン番号**（例：`v1.0.0`）が表示されます。

---

## 2. 画面の構成

ログイン後、以下のタブが表示されます。

| タブ | 用途 |
|------|------|
| 名簿管理 | 会員情報の閲覧・登録・編集 |
| 会議管理 | 会議の作成、事前入力、当日受付 |
| メール送信 | 一斉メールの作成・送信 |
| テンプレート | メール本文テンプレートの管理 |
| 設定 | 担当者・接続設定（管理者向け） |
| 送信履歴 | 送信済みメールの確認 |

## 3. 名簿管理

### 3-1. 会員一覧の表示

「名簿管理」タブを開くと会員一覧が表示されます。

- **キーワード検索**：事業所名・氏名・会員番号で絞り込めます
- **役職フィルター**：特定の役職のみ表示できます
- **議員退任者を含む**：チェックすると退任者も表示されます
- **A- / A+** ボタン：文字サイズを調整できます（設定は次回起動時も維持されます）
- **列見出しクリックでの並べ替え**：各列の見出しをクリックするとその列で並べ替えられます。「会議所役職」列は役職の表示順→就任順→フリガナの順で並びます
- **副会頭の就任順** ボタン：副会頭の並び順（就任順）を個別に設定できます。ダイアログが開くので、対象者を選択して上下ボタンまたはドラッグで順序を入れ替えて保存します

会員が1件も登録されていない場合は「会員データがまだ登録されていません。『追加』ボタン、または『ファイル→インポート』から会員を登録してください。」というガイダンスが表示されます。

### 3-2. 会員の追加

「追加」ボタンをクリックして会員編集ダイアログを開きます。

| 項目 | 必須 | 説明 |
|------|------|------|
| 会員番号 | ◎ | 重複不可 |
| 会議所役職 | | 副会頭・常議員など |
| 委員会 | | 所属する委員会（未所属も可、設定タブで管理） |
| 事業所名 | ◎ | |
| 事業所名フリガナ | | 検索・受付に使用。入力欄からフォーカスを外すと自動で半角カタカナに変換されます |
| 役職名 | | 代表取締役など |
| 氏名 | ◎ | |
| 氏名フリガナ | | 検索・受付に使用。事業所名フリガナと同様に自動で半角カタカナに変換されます |
| 備考 | | |
| メールアドレス | | 最大5件・ラベル付き（`○○@△△.co.jp`のような形式かどうかを自動チェックします） |
| 顔写真 | | JPG/PNG/BMP（証明写真サイズ推奨） |

「保存」をクリックして登録します。メールアドレスの形式が正しくない場合は警告が表示され、修正するまで保存できません。

> 委員会そのものの追加・編集・削除は「設定タブ」の「役職・委員会管理」で行います（[8-4](#8-4-役職委員会の管理)参照）。

### 3-3. 会員の編集

一覧から会員をダブルクリック、または選択して「編集」ボタンをクリックします。  
編集時は**変更理由の入力が必須**です。

### 3-4. 議員退任処理

退任した会員を選択して「議員退任」ボタンをクリックすると、「議員退任処理しますか？一覧から非表示になりますが、変更履歴は保持されます」という確認が表示されます。  
「はい」を選ぶと一覧から非表示になります（データは削除されません）。「議員退任者を含む」チェックをオンにすると、退任者もグレー表示で一覧に含まれます。

### 3-5. 顔写真の登録

会員編集ダイアログの「顔写真」グループで「写真を選択」をクリックします。  
証明写真サイズの画像（JPG/PNG）を選択してください。写真はデータベースに保存されます。

### 3-6. インポート（Excelから一括登録）

「インポート」ボタンをクリックし、Excel ファイルを選択します。  
列名から「委員会」「所属委員会」「メール」等の見出しを自動で認識し、列マッピング画面にあらかじめ対応付けした状態で表示します（内容は登録前に確認・修正できます）。  
列の対応付けを確認して「インポート実行」をクリックします。

> メールアドレスの形式が正しくない行は、そのアドレスだけを除外して会員自体は登録されます。除外されたアドレスはインポート完了後のエラー一覧に表示されるので、必要に応じて名簿管理から個別に修正してください。

### 3-7. エクスポート

「エクスポート」ボタンをクリックして Excel または CSV 形式で出力します。委員会列・メールアドレス列も含めて出力されます。

### 3-8. 変更履歴の確認

会員を選択して「変更履歴」ボタンをクリックすると、過去の変更内容と変更理由を確認できます。

## 4. 会議管理・受付

### 4-1. 会議の作成

「会議管理」タブ上部の「新規作成」ボタンをクリックします。

| 項目 | 説明 |
|------|------|
| 会議名 | 例：第50回定時総会 |
| 開催日 | カレンダーから選択 |
| 対象者 | 全員 または 役職指定（常議員会など） |

### 4-2. 事前入力タブ

会議作成後、「事前入力」タブで出欠状況を事前に登録します。

- **ステータス**：未回答 / 出席 / 代理 / 委任 / 欠席
- 代理の場合は代理者の役職名・氏名も入力できます
- キーワード検索・ステータスフィルターで絞り込めます

#### 委任について

- 委任は本人が書面で出席を委任する形式です（代理人の来場なし）
- 事前に「委任」と入力しておくと、受付タブを開いた際に自動的に当日受付も「委任」にセットされます

### 4-3. 受付タブ

当日の受付業務を行います。

**左側の写真パネル：** 行を選択すると顔写真と氏名が表示されます。

**当日受付の列：** ドロップダウンから選択します。
- 空欄（未受付）
- 出席
- 代理
- 委任
- 欠席

**集計バー（上部）：** 出席・代理・委任・欠席・未受付・合計が3秒ごとに自動更新されます。議決権数は「当日出席者数（出席＋代理）＋委任－監事の出席者数」で計算され、画面に計算式と内訳が表示されます。

**検索：** 事業所名・氏名・会員番号で絞り込めます。  
**A- / A+** ボタンで文字サイズを調整できます。

**当日受付をExcel出力：** 当日受付の入力結果、集計、議決権数の計算式をExcelファイルへ保存します。明細には会員番号・事前回答を含めず、名簿の下部に集計を配置し、A4縦向きで印刷できます。

**議事録用氏名：** 出席・代理・委任の氏名を画面の表示順で1行にまとめます。氏名中の空白は除去され、代理には「㈹」、委任には「(委任)」が付きます。「テキストをコピー」でWordの議事録へ貼り付けられます。

### 4-4. 受付ログタブ

受付操作（誰がいつ何を操作したか）のログを確認できます。

### 4-5. 出欠状況のHTML出力

受付タブでの操作のたびに、設定タブで指定した出力先に出欠状況のHTMLファイルが自動更新されます。  
共有フォルダに出力先を設定すれば、他のPCのブラウザからも出欠状況を確認できます。  
出力先の設定方法は [8-5](#8-5-出欠状況html出力の設定) を参照してください。

## 5. メール送信

### 5-1. 送信の流れ

**Step 1 → Step 2 → Step 3 → Step 4** の順に設定します。

### Step 1：宛先条件

宛先の絞り込み方法を4つから選びます（ラジオボタンでいずれか1つ）。

| 方法 | 内容 |
|------|------|
| 名簿から選択（既定） | 送信先一覧から対象の会員に手動でチェックを入れます |
| 役職で選ぶ | 会議所役職（複数選択可）で自動的に絞り込みます |
| 委員会で選ぶ | 委員会（複数選択可）で自動的に絞り込みます |
| 会議の出欠で選ぶ | 会議を選択し、出欠ステータス（未回答／欠席／出席／委任／代理、複数選択可）で自動的に絞り込みます |

- **全選択 / 全解除** ボタンで送信先一覧を一括操作できます
- **検索欄** で事業所名・氏名・会員番号・フリガナで絞り込めます
- **A- / A+** ボタンで文字サイズを調整できます

> メールアドレスが未登録の会員は送信対象になりません。画面下部に件数が表示されます。

#### 「会議の出欠で選ぶ」の自動切り替えについて

会議の開催日を基準に、どちらの出欠データを使うかが自動的に切り替わります。

- 会議日より前（開催前）：**事前入力**タブに登録した出欠状況を使用します
- 会議日以後（開催日当日・開催後）：**受付タブ**で記録した当日受付の状況を使用します

画面上に、現在どちらのデータを参照しているかがラベルで表示されます。

### Step 2：テンプレート・署名選択

送信するメールのテンプレートと署名をドロップダウンから選択します。  
選択すると件名・本文欄に内容が反映され、その場で一時的に編集できます。

- プレースホルダーボタン（`{事業所名}` `{役職名}` `{氏名}` `{会議所役職名}`）をクリックすると、本文のカーソル位置にタグが挿入されます
- 「本文を拡大して編集」ボタンで大きな編集画面を開けます
- 「テンプレートとして保存」ボタンで、編集中の件名・本文を新規テンプレートとして保存、または選択中のテンプレートに上書き保存できます

### Step 3：添付ファイル（任意）

「添付ファイルを使用する」にチェックを入れると設定項目が表示されます。

**全社共通ファイル：** 全員に同じファイルを添付します（複数ファイル可）。  
**会社別フォルダ：** フォルダとファイル名ルール（例：`{会員番号}_*.pdf`）を指定すると、`*`をワイルドカードとして会員番号に一致するファイルを各社に個別添付します。1件の会員に複数ファイルが一致した場合はすべてまとめて添付されます。

「マッチング確認」ボタンで、各社ごとに見つかったファイルを一覧確認できます。見つからない会員は警告表示され、スキップして続行するか中止するかを選べます。

> マッチング確認から送信実行までの間にファイルが移動・削除された場合、その宛先は送信時にエラーとして扱われます（添付なしのまま無言で送信されることはありません）。

### Step 4：最終確認・送信

1. **ジョブ名** を入力します（例：2026年6月 総会案内）
2. 必要に応じて **CC**・**BCC** を入力します。複数のアドレスはカンマまたはセミコロンで区切ります
3. **テスト送信** ボタン（設定タブに登録したテスト送信先アドレスがボタンに表示されます）で、1通送信して確認できます
4. **送信実行** ボタンをクリックすると確認ダイアログが表示されます
   - 添付ファイルの合計サイズが宛先ごとに3MBを超えている場合は、対象の宛先名を挙げた警告が表示されます。「はい」を選ぶとその宛先を除外して続行、「いいえ」を選ぶと送信を中止できます
5. 内容を確認して「送信する」をクリックすると送信が開始されます

設定タブで **テストモード** が有効な場合は、画面に黄色の注意表示が出ます。この状態で送信実行しても、本来のTo・CC・BCCには送られず、全メールが設定済みのテスト送信先へ送られます。件名には「【テストモード】」が付き、本文の先頭に本来のTo・CC・BCCが記載されます。

送信中は宛先間に自動的に間隔を空けて送信します（Microsoft 365の送信件数制限に抵触しないようにするためです）。通信エラー等が5件連続して発生した場合は、それ以上の送信を自動的に中断します（中断・中止した場合、未送信分は送信履歴に「スキップ」として記録されます）。

**すべてクリア** ボタンで Step 1〜3 の設定をすべて初期化できます。

## 7. 送信履歴

「送信履歴」タブで過去の送信記録を確認できます。

- 送信日時・ジョブ名・担当者・送信件数が表示されます
- 個別の送信先・件名・本文も確認できます
- タブを開くたびに一覧が自動更新されます
- 列見出しをクリックすると、その列で並べ替えられます
- 送信完了から1年以上経過した履歴は、ログイン時に自動的に削除されます

## 8. 設定タブ（管理者が初期設定を行う）

「設定」タブは、**アプリを新しいPCに導入したとき**に管理者が接続情報を入力する画面です。  
職員の方は通常この画面を操作する必要はありません。管理者の指示があった場合のみ操作してください。

### 8-1. Microsoft 365（メール送信）の設定

「Microsoft 365」タブに、管理者から渡された情報を入力します。

| 項目 | 説明 |
|------|------|
| テナントID | Microsoft 365 組織のID（英数字とハイフンの文字列） |
| クライアントID | Entra ID に登録したアプリのID |
| テスト送信先 | テスト送信の届け先メールアドレス |
| テストモード | 有効にすると、本来のTo・CC・BCCへ送らず、全件をテスト送信先へ振り替えます |

入力後「**接続テスト**」をクリックすると、Microsoft 365 のサインイン画面が表示されます。**自分自身の**Microsoft 365 アカウントでサインインし、「接続に成功しました」と表示されることを確認します。  
確認できたら「**設定を保存**」をクリックします。

> 送信元メールアドレスは固定ではなく、メール送信時にサインインした担当者本人のアドレスになります。サインインは一度行えば、その端末では次回以降自動的に認証されます（担当者ごと・端末ごとに初回のみサインインが必要です）。

### 8-2. データベース接続の設定

「データベース接続」グループで、どのデータベースに接続するかを設定します。

#### SQLite（1台のみで使う場合）

「**SQLite（1台用）**」を選択します。追加の設定は不要です。  
データは同じPC内のファイル（`cci_mail.db`）に保存されます。

#### PostgreSQL（複数台で共有する場合）

「**PostgreSQL（ネットワーク・複数台用）**」を選択し、管理者から渡された情報を入力します。

| 項目 | 説明 |
|------|------|
| ホスト名 / IPアドレス | データベースサーバーのIPアドレス（例：`192.168.1.20`） |
| ポート番号 | 通常は `5432`（変更していなければそのまま） |
| データベース名 | 通常は `cci_mail` |
| ユーザー名 | データベースのユーザー名 |
| パスワード | データベースのパスワード |

入力後「**接続テスト**」をクリックし、「接続に成功しました」と表示されることを確認します。  
確認できたら「**設定を保存（要再起動）**」をクリックし、アプリを一度終了して再起動します。

> 接続テストが失敗する場合は、サーバーPCが起動しているか、入力内容に誤りがないか確認のうえ、管理者に連絡してください。

### 8-3. 職員の登録・管理者権限

管理者権限を持つ担当者でログインすると「**職員管理**」タブが表示されます（一般の担当者には表示されません）。

- 「追加」ボタン → 担当者名を入力して登録（ログイン画面のドロップダウンに表示されます）
- 有効/無効の切り替え → 退職者などを無効化するとログイン画面の選択肢から外れます（データは削除されないため、送信履歴等の担当者名はそのまま保持されます）
- 「管理者権限 切替」ボタン → 選択した担当者に管理者権限を付与・剥奪します。管理者権限を持つ担当者のみ「職員管理」「データ管理」タブを操作できます

### 8-4. 役職・委員会の管理

「**役職・委員会管理**」タブで、会議所役職と委員会のマスタを管理します。

- **役職**：追加・編集・削除、表示順の並び替え
- **委員会**：追加・編集・削除。所属会員がいる委員会を削除しようとすると、所属会員数を含む確認メッセージが表示されます（削除すると所属設定は解除されます）

### 8-5. 出欠状況HTML出力の設定

「**出力設定**」タブで、会議の出欠状況を出力するHTMLファイルの保存先を設定します。

- 「出力先ファイル」に保存先パスを指定します（共有フォルダを指定すると、他のPCのブラウザからも確認できます）
- 空白のままにするとHTML出力は行われません
- 受付タブでの操作のたびに自動でファイルが更新されるほか、「今すぐ出力」ボタンで手動出力もできます
- PostgreSQL（複数台運用）モードでは、この設定はデータベースを通じて全端末で共有されます。SQLite（1台運用）モードでは端末ごとの個別設定です

## 9. アップデートの通知

新しいバージョンが公開されると、起動時または30分ごとの自動確認後に、画面上部へ黄色いバナーが表示されます。

```
新しいバージョン v1.0.1 が利用可能です        [ダウンロード]
```

1. 「ダウンロード」ボタンをクリックするとインストーラーが自動でダウンロードされます
2. ダウンロード完了後「今すぐ更新して再起動」ボタンが表示されます
3. クリックするとインストーラーが起動し、アプリが最新版に更新されます

すぐに確認したい場合は、メニューの「**ヘルプ → 更新を確認**」をクリックしてください。最新版の場合は現在のバージョンが表示され、確認できない場合はネットワーク接続などの原因が表示されます。

## 10. よくある質問

**Q. テンプレートを選択したのにプレビューが表示されない**  
A. テンプレートを選択後、「テンプレートを選択してください」に戻すと消えます。再度テンプレートを選択してください。

**Q. 送信先にチェックを入れたのに「0件選択」と表示される**  
A. チェックを入れた会員にメールアドレスが登録されていない可能性があります。名簿管理でメールアドレスを確認してください。

**Q. テスト送信はどこに届きますか？**  
A. 設定タブの「テスト送信先」に登録されているメールアドレスに届きます。

**Q. 受付タブで写真が表示されない**  
A. 名簿管理の編集ダイアログで顔写真を登録してください。写真未登録の会員は「写真なし」と表示されます。

**Q. 文字が小さくて見づらい**  
A. 各タブに「A-」「A+」ボタンがあります。クリックで文字サイズを調整できます（次回起動時も設定が維持されます）。

**Q. メール送信・テスト送信のときにMicrosoft 365のサインイン画面が表示される**  
A. 正常な動作です。送信元は固定アドレスではなく、送信操作を行った担当者本人のアカウントになるため、その端末で初めて送信操作をしたときにサインインが必要です。一度サインインすれば、以降その端末では自動的に認証されます。

**Q. 委員会や会議所役職を追加・変更したい**  
A. 「設定」タブの「役職・委員会管理」で行います。管理者に依頼するか、権限があれば自分で操作してください。

**Q. 送信結果に「添付ファイルが見つかりません」というエラーが出た**  
A. マッチング確認を行った後に、対象のファイルが移動・削除・リネームされた可能性があります。フォルダ内のファイルを確認し、再度「マッチング確認」を行ってから送信し直してください。

**Q. 「メールアドレスの形式が正しくありません」と表示されて保存・インポートできない**  
A. アドレスに全角文字や余分な空白が含まれていないか確認してください（例：`info@example.com` のように半角で入力します）。インポート時は該当アドレスのみ除外して会員自体は登録されるため、後から名簿管理で個別に修正できます。

**Q. 一斉送信の途中で自動的に止まってしまった**  
A. 通信エラーなどが5件連続で発生すると、それ以上の送信を防ぐため自動的に中断する仕様です。ネットワーク接続やMicrosoft 365の認証状態を確認し、必要に応じて未送信の宛先を選び直して再送信してください。中断前に送信できなかった宛先は「送信履歴」にスキップとして記録されます。
