# サーバーPC変更手順

このアプリのデータは「SQLite（1台用）」または「PostgreSQL（複数台用）」のいずれかで管理されています。  
現在どちらを使用しているかは、アプリの **設定タブ → データベース接続** で確認できます。

---

## A. SQLite を使っている場合（1台運用）

SQLite はデータがファイル1つ（`cci_mail.db`）に保存されています。  
PC を変えるときはこのファイルをコピーするだけです。

### 手順

#### 1. 旧PCでデータファイルの場所を確認する

アプリフォルダ内の `cci_mail.db` がデータファイルです。  
（アプリの設定タブ → データベース接続 に「SQLiteファイルパス」が表示されている場合はそのパス）

#### 2. データファイルをコピーする

`cci_mail.db` をUSBメモリや共有フォルダ経由で新しいPCにコピーします。

#### 3. 新PCにアプリをインストールする

アプリを新しいPCにインストールし、コピーした `cci_mail.db` をアプリフォルダに配置します。

#### 4. 動作確認

アプリを起動し、名簿・テンプレート・送信履歴が表示されれば完了です。

---

## B. PostgreSQL を使っている場合（複数台運用）

PostgreSQL はサーバーPC上で動作しており、各クライアントPCはネットワーク経由で接続しています。  
サーバーPCを変更する場合は、以下の手順で行います。

### 全体の流れ

```
1. 旧サーバーのデータをバックアップ
2. 新サーバーに PostgreSQL をインストール・設定
3. バックアップデータを新サーバーに復元
4. 各クライアントPCの接続先を変更
5. 動作確認
```

---

### 手順1：旧サーバーのデータをバックアップする

旧サーバーPC で **コマンドプロンプト（管理者）** を開き、以下を実行します。

```
pg_dump -U postgres -Fc cci_mail > C:\backup\cci_mail_backup.dump
```

- `-U postgres` の部分は実際のPostgreSQLユーザー名に合わせてください
- `cci_mail` は使用しているデータベース名です（設定タブで確認できます）
- パスワードを求められたら入力してください

バックアップファイル（`cci_mail_backup.dump`）をUSBメモリや共有フォルダにコピーしておきます。

---

### 手順2：新サーバーにPostgreSQLをインストールする

1. PostgreSQL の公式サイト（https://www.postgresql.org/download/windows/）からインストーラーをダウンロードして実行します
2. インストール時に設定するパスワードを控えておいてください
3. インストール完了後、**コマンドプロンプト（管理者）** で以下を実行してデータベースを作成します

```
psql -U postgres -c "CREATE DATABASE cci_mail;"
```

4. アプリ専用のユーザーを作成する場合（任意）

```
psql -U postgres -c "CREATE USER cci_user WITH PASSWORD 'パスワード';"
psql -U postgres -c "GRANT ALL PRIVILEGES ON DATABASE cci_mail TO cci_user;"
```

---

### 手順3：バックアップデータを新サーバーに復元する

バックアップファイルを新サーバーPCに移し、**コマンドプロンプト（管理者）** で実行します。

```
pg_restore -U postgres -d cci_mail C:\backup\cci_mail_backup.dump
```

完了メッセージが表示されれば復元完了です。

---

### 手順4：各クライアントPCの接続先を変更する

全クライアントPC（アプリを使う全PC）で以下を行います。

1. アプリを起動してログインする
2. **設定タブ → データベース接続** を開く
3. **「PostgreSQL（ネットワーク・複数台用）」** が選択されていることを確認する
4. 以下の項目を新サーバーの情報に書き換える

| 項目 | 内容 |
|------|------|
| ホスト名 / IPアドレス | 新サーバーPCのIPアドレス（例：192.168.1.20） |
| ポート番号 | `5432`（変更していなければそのまま） |
| データベース名 | `cci_mail`（変更していなければそのまま） |
| ユーザー名 | PostgreSQLのユーザー名 |
| パスワード | PostgreSQLのパスワード |

5. 「**接続テスト**」ボタンをクリックして「接続に成功しました」と表示されることを確認する
6. 「**設定を保存（要再起動）**」をクリックする
7. アプリを終了して再起動する

---

### 手順5：動作確認

全クライアントPCでアプリを起動し、以下を確認します。

- [ ] 名簿管理タブに会員一覧が表示される
- [ ] 会議管理タブに会議一覧が表示される
- [ ] 送信履歴タブに履歴が表示される
- [ ] 受付タブで複数PCから同時に操作できる

---

## よくある質問

**Q. 新サーバーPCのIPアドレスはどこで確認できますか？**  
新サーバーPC でコマンドプロンプトを開き `ipconfig` を実行すると確認できます。  
`IPv4 アドレス` に表示されている数字（例：192.168.1.20）がIPアドレスです。  
なお、IPアドレスが変わらないよう新サーバーPCには **固定IPアドレス** を設定することをお勧めします。

**Q. 「接続テスト失敗」と表示される場合は？**  
以下を確認してください。
- 新サーバーPCの電源が入っている
- PostgreSQL のサービスが起動している（新サーバーPC のタスクバーで確認）
- Windows ファイアウォールで PostgreSQL のポート（5432）が許可されている
- ホスト名/IPアドレス・ユーザー名・パスワードが正しい

**Q. 旧サーバーPCはいつ停止してよいですか？**  
全クライアントPCで動作確認が完了し、新サーバーへの移行が確認できた後に停止してください。  
移行直後はしばらく旧サーバーも起動したままにしておくと安心です。

**Q. app_config.json とは何ですか？**  
アプリフォルダ内の `app_config.json` に接続設定が保存されています。  
設定タブで保存するとこのファイルが更新されます。  
各クライアントPCに個別に存在するため、全台で設定変更が必要です。
