商工会議所メール配信システム
使い方マニュアル

対象バージョン: v1.1.0

このマニュアルについて

  • 会員（事業所）へのメール一斉配信・名簿管理・会議出欠管理を行うアプリの操作ガイドです。
  • 各機能はウィンドウ上部のタブで切り替えます。
  • データベース接続やMicrosoft 365の設定については、管理者マニュアルをご覧ください（管理者権限を持つ職員のみ「ヘルプ」メニューから閲覧できます）。

概要

このアプリは、商工会議所の会員（事業所）に対するメール一斉配信と、それに関連する名簿・会議出欠の管理を行うシステムです。

タブ名主な用途
名簿管理会員（事業所）の登録・編集・インポート/エクスポート
会議管理会議の登録と出欠状況の確認・集計
メール送信宛先を絞り込んでメールを一斉送信
テンプレートよく使う件名・本文をテンプレートとして登録（全職員で共有）
設定Microsoft 365・署名・委員会・職員管理などの各種設定
送信履歴過去の送信ジョブと送信結果（成功/エラー）の確認
名簿・会議・テンプレート・送信履歴などのデータは、全職員で共有されます（管理者が設定したデータベースに保存）。一方、署名は職員ごとに個別に管理され、他の職員の署名は見えません。

ログイン

アプリを起動すると、最初にログイン画面が表示されます。

  1. プルダウンから自分の名前を選択します。
  2. 「ログイン」ボタンをクリックします。
このアプリのログインにパスワードはありません。プルダウンから自分の名前を選ぶだけの、信頼ベースの簡易的な仕組みです。誤操作防止・画面整理が目的で、不正アクセス防止のためのものではありません。

閲覧専用ログイン

出欠確認だけを行いたい場合は、「閲覧専用でログイン」を選ぶと、編集ができない状態で会議管理タブのみが表示されます。

職員が誰も登録されていない場合

初めてアプリを使うとき、まだ誰も職員登録されていない状態では、ログイン画面に「職員を追加」ボタンが表示されます。ここで最初に登録した人は、自動的に管理者になります（後述の「職員管理」参照）。

名簿管理

会員（事業所）の情報を一覧で管理します。写真・会員番号・会議所役職・委員会・事業所名・氏名・役職名・メールアドレスなどを確認できます。

会員の追加・編集

  1. 「追加」ボタンで新規会員を登録します（会員番号・事業所名・氏名・メールアドレス等を入力）。
  2. 一覧から会員を選択し「編集」ボタンで内容を修正します。
  3. 「変更履歴」ボタンで、その会員の過去の変更内容を確認できます。
  4. 議員を退任した会員は「議員退任」ボタンで非表示扱いにできます（データ自体は削除されず、変更履歴として残ります）。
  5. 「副会頭の就任順」ボタンで、副会頭が複数名いる場合の掲載順（就任が古い順）を設定できます。役職そのものの一覧・表示順は設定 > 役職・委員会管理で管理します。
キーワード検索欄で事業所名・氏名・会員番号から絞り込めます。「役職」プルダウンで役職ごとの絞り込みも可能です。

インポート・エクスポート

「ファイル」メニューから以下の操作ができます。

操作説明
インポートExcel/CSVから名簿を一括登録・更新。列マッピングとデータプレビューを確認してから実行できます。
インポート取り消し直前のインポートを取り消し、インポート前の状態に戻します。
エクスポート現在の名簿をExcel/CSVとして出力します。
インポートで既存会員と同じ会員番号のデータを取り込むと、既存の内容が上書き更新されます。事前にデータプレビューで内容をよく確認してください。

会議管理

会議（総会・部会など）を登録し、会員ごとの出欠状況（未回答・欠席・出席・委任・代理）を管理します。

  • 会議は特定の役職のみを対象にすることも、全会員を対象にすることもできます。
  • 各テーブルは列の表示/非表示を切り替えられます（ヘッダー右クリックまたは列設定ボタン）。
  • 出欠状況は一覧からその場で更新できます。
  • 「事前入力」タブの「Excel出力」ボタンから、出欠一覧（通し番号・会議所役職・事業所名・所属役職・氏名・事前ステータス・代理情報）を会議所役職順に並べたExcelファイルとして保存できます。A4縦向きでの印刷を想定したページ設定（横幅を1ページに収め、行数が多い場合は自動的に2ページ目以降へ続く）になっています。

メール送信

メール送信タブは5つのステップで構成されています（差し込みデータの利用など一部の機能は開発者向けのため、通常は表示されません）。

Step1：宛先条件

宛先の絞り込み方法を選びます。

モード説明
名簿から選択（既定）右側の宛先一覧から手動でチェックを入れて選びます。「表示中を全選択/全解除」ボタンで一括操作も可能です。
役職で選ぶ会議所役職にチェックを入れると、該当する会員が自動的に選択されます（複数選択可）。
委員会で選ぶ委員会にチェックを入れると、該当する会員が自動的に選択されます（複数選択可）。
会議の出欠で選ぶ会議と出欠ステータス（未回答・欠席・出席など）を指定して絞り込みます。

Step2：テンプレート・署名選択

  • プルダウンからテンプレートを選ぶと、件名・本文・署名が自動入力されます。
  • プレースホルダーボタン（{事業所名} {役職名} {氏名} {会議所役職名}）をクリックすると、本文のカーソル位置に差し込まれます。送信時に各会員の情報に自動置換されます。
  • 署名はプルダウンから自分の署名を選びます（署名は職員ごとに個別管理です。登録方法は設定 > 署名管理参照）。
  • 本文を作成したら「テンプレートとして保存」ボタンで、次回以降も使えるテンプレートとして登録できます。既存のテンプレートを選択中に保存すると上書き確認が出ます。

Step4：添付ファイル（任意）

「添付ファイルを使用する」にチェックを入れると詳細項目が展開されます。

  • 全社共通ファイル：全員に同じファイルを添付します。
  • 会社別ファイル：会員番号に対応するファイルをフォルダから自動で添付します。ファイル名ルールは {会員番号}_*.pdf のように会員番号の直後にアンダースコアを挟む形式を推奨します（例：A001_請求書.pdf）。「*」部分は任意の文字列にマッチし、1人に複数ファイルが一致した場合は全てまとめて添付されます。
チェックを外すと添付ファイルの設定内容は保持されたまま非表示になりますが、その状態で送信すると添付ファイルは付きません。再度チェックを入れると設定内容が復元されます。

Step5：最終確認・送信

  • テスト送信：設定タブで登録したテスト送信先アドレスに、選択中の宛先のうち1件分の差し込み内容でテストメールを送ります（実際の宛先には送信されません）。テスト送信先が未設定の場合はボタンに「未設定」と表示されます。
  • 差し込みプレビュー：実際に送信される内容を宛先ごとに確認できます。
  • 送信実行：ジョブ名を入力して送信します。送信後は取り消せません。
  • 送信を中止：送信中に中止すると、未送信分はスキップされます（送信済みの分は取り消せません）。

テンプレート管理

よく使う件名・本文をテンプレートとして登録・編集・削除します。テンプレートは全職員で共有されます。

  • プレースホルダーボタンで本文に差し込み項目を挿入できます。
  • デフォルト署名を指定できます（送信タブでテンプレートを選ぶと自動的に反映されます）。
  • 編集中に保存せず他のテンプレートを選ぼうとすると、未保存の変更を破棄するか確認が出ます。
  • Ctrl+S で保存できます。

送信履歴

過去の送信ジョブの一覧と、各ジョブの宛先ごとの送信結果（成功・エラー・スキップ）を確認できます。CSV出力も可能です。

送信結果の「成功」は、送信サーバー（Microsoft 365）が送信要求を受け付けたことを示します。実際に相手の受信箱に届いたか（迷惑メール判定など）までは確認できません。

設定

Microsoft 365

メール送信に必要なテナントID・クライアントID、およびテスト送信先アドレスを設定します。詳しい設定手順は管理者マニュアルを参照してください。テスト送信先は職員ごとに個別のPC設定であり、他の職員とは共有されません。

署名管理

自分専用の署名を登録・編集できます（他の職員の署名は見えません）。「デフォルトに設定」した署名は、送信タブ・テンプレートタブで自動的に選択されます。

役職・委員会管理

会議所役職と委員会の一覧を、左右に並んだ画面でまとめて管理します。ここで登録した役職・委員会は、名簿の会員ごとの設定や、送信タブの「役職で選ぶ」「委員会で選ぶ」モードで使われます。

  • 役職：追加・名称変更・削除に加えて「↑ 上へ」「↓ 下へ」ボタンで表示順を並べ替えられます（例：会頭→副会頭→常議員→監事→議員）。
  • 委員会：追加・名称変更・削除ができます（並び替えは登録順です）。
  • 会員が所属している役職・委員会を削除しようとすると、件数を示す確認ダイアログが表示されます。削除すると該当会員の所属設定は解除されます（会員データ自体は削除されません）。

職員管理（管理者のみ）

この画面は管理者権限を持つ職員にのみ表示されます。

  • 職員の追加、有効/無効の切り替えができます。
  • 「管理者にする」チェックを入れて追加すると、その職員も管理者になります。
  • 既存の職員の管理者権限は「管理者権限 切替」ボタンで変更できます。最後の1人の管理者を非管理者にしようとすると、確認の警告が表示されます（誰も職員管理にアクセスできなくなるため）。
管理者が0人になると、以後は職員が誰も職員管理タブにアクセスできなくなります。復旧するには職員を全員無効化してログイン画面から登録し直す（自動的に管理者になります）か、管理者に直接データベースを操作してもらう必要があります。
